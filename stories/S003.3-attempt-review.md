# User Voice

As a parent, I want to see which tasks he attempted, what he answered, and whether he passed, so that I can see what he has learned and where he is stuck.

# Use Cases

- A page lists attempts for a client, newest first, with the task name, start time, outcome, and duration.
- Opening an attempt shows the stored answers and results in a readable form. Quiz stories add type-specific detail. This story must at least show the raw record cleanly for `parent_check` and for a generic answer list.
- The page is not available to the child.

# Acceptance Criteria

- [ ] A success, a failure, and an abandonment each appear with the correct outcome and household-local times.
- [ ] An attempt with a list of answers shows each answer, not only the final outcome.
- [ ] The page is protected by the same barrier as the usage report in S002.2.
- [ ] The parent action that marks a `parent_check` attempt successful is on this page, and it is the only way that task type reaches success.

# Notes

Depends on S003.1 and S003.2. Later quiz stories extend the detail view rather than building a second history.
