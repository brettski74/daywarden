# User Voice

As a parent, I want to write capitalisation pools, set up capitalisation tasks, and read his attempts in the portal or
through an agent, so that I never have to edit the pool files by hand.

# Behaviour

## Capitalisation pools pages

- [ ] Asset Administration has a Capitalisation Pools link to `/parent/assets/capitalisation-pools`. The list, create,
      rename, delete with its refusal while a task names the pool, sign-in, and data addresses work as on Parts of
      Speech Pools in S031.2.
- [ ] A pool page shows Name and Level of difficulty as in S031.2, then one row per sentence holding a text box, a
      Level of difficulty box with the pool's value as its placeholder, and a delete button, then Add sentence.
- [ ] Add sentence and Alt+N add an empty row at the end and put the cursor in it.
- [ ] Pasting several lines into a sentence box puts the first line in that row and each other non-empty line in a new
      row below it. Pasting three lines into an empty pool gives three sentences.
- [ ] A sentence that is empty, has no capital, or appears twice in the pool, and a difficulty outside 0.5 to 10, are
      problems shown under the row that block Save.
- [ ] Save, Ctrl+S, the unsaved-changes prompt, refusal after a hand edit, and the config history commit work as in
      S031.2. A saved sentence with no difficulty of its own is written as a plain string.

## Capitalisation task page

- [ ] `/parent/tasks/capitalisation/<name>` shows Timeout, Correct Answers Required, Minimum Questions, Maximum
      Questions, and Pools, and saves them, as the parts of speech task page does in S031.3, with no Parts of speech
      filter. Empty Timeout shows `60s` as its placeholder.
- [ ] New task (S027) offers the Capitalisation type, and the Task Administration sidebar lists capitalisation tasks
      with the other types.

## Attempts

- [ ] Capitalisation attempts appear in the attempts overview and trend as `capitalisation/<name>`, with figures as
      parts of speech has in S035.1: points against the pass mark, questions against the maximum, wrong, timeouts,
      and time answering.
- [ ] The attempt page shows a summary of its last run, then each sentence in order, with each try's clicked words
      marked blue or red as in S040.1's answer, the points it earned or timeout, and the time taken, then its expired
      runs. A sentence right on its second try shows the first try with its red words and the second all blue.

## MCP tools

- [ ] The MCP page and `mcp.yaml` have a `capitalisation_pools` class with create, read, update, and delete.
- [ ] Capitalisation pools have tools to list, read, create, update, rename, and delete them, each needing its
      `capitalisation_pools` permission, which work as the sentence pool tools do in S036.1 and S036.2. Their
      sentences are in the pool file's form. Adding a sentence with no capital is refused with the page's reason.
- [ ] The task tools of S036.2 create, read, and change `capitalisation` tasks, with their pools by id. An id that is
      not a capitalisation pool, including a parts of speech pool's id, is refused.
- [ ] The attempt tools of S036.1 read capitalisation attempts with each try's clicked words.

## Docs

- [ ] `docs/parent-portal.md` names the Capitalisation Pools pages and the capitalisation task page. The MCP docs list
      the new class and tools.

# Notes

Depends on S040.1, S031.2 and S031.3 for the pool and task pages, S035.1 for attempt figures, and S036 for the MCP
tools. The pool page is a simpler copy of the parts of speech pool page, with no word sorting. Build it from the same
pool list and page shell rather than a second copy.

Out of scope: statistics on which words he gets wrong across attempts, as S035.3 plans for parts of speech.
