Title: Word pools, targets, and audio

# User Voice

As a parent, I want to choose this week's spelling words and a larger revision pool, and I want the number he must get right to change by weekday.

# Use Cases

- A spelling task has two lists of words. Each word has a word-only audio file and a sentence audio file, both recorded by the parent and stored as WAV. The word clip is the word spoken on its own, slowly and clearly. The sentence clip is one sentence that contains the word.
- Letter audio files, a to z, plus hyphen and apostrophe, are recorded once and reused by practice mode. The config points at these files. It does not embed the audio.
- The number of this week's words that must be spelled correctly can be set per weekday, plus a default for days without an override.
- The number of revision words that must be spelled correctly is a single configured integer.
- The spelling timeout is one value in milliseconds. It does not shrink as the quiz goes on.

# Acceptance Criteria

- [ ] Either pool can be empty of any assumed size. A this-week pool of 3 and a revision pool of 40 is valid. A this-week pool of 40 and a revision pool of 3 is valid.
- [ ] A word missing either audio file is rejected as invalid configuration.
- [ ] On a Wednesday with a Wednesday target of 5 and a default of 9, the task requires 5 correct this-week words. On a Thursday with no override, it requires 9.
- [ ] The revision target is the same on both of those days.
- [ ] The timeout is stored in milliseconds and is the same for the first word and the last word.
- [ ] A required this-week count larger than the this-week pool is rejected. A required revision count larger than the revision pool is rejected, because the quiz cannot invent new revision words beyond that pool.

# Notes

Depends on S003.1. The parent supplies the recordings. S005.4 can generate files later, and this story will accept those files too, but it does not wait for that. A missing file is invalid configuration, reported when the task is loaded, not halfway through a quiz.
