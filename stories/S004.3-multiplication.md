# User Voice

As a child, I want to practice multiplication with a proper times sign, so that the question looks like the one I see on paper.

# Use Cases

- The question displays `m × n =`, using the multiplication sign `×` (U+00D7), not an asterisk and not the letter x.
- The expected answer is `m * n`.

# Acceptance Criteria

- [ ] A drawn pair of 6 and 7 displays `6 × 7 =` and accepts 42 as the only correct answer.
- [ ] The character on screen is `×`, confirmed in the page, not `x` and not `*`.
- [ ] The task uses the shell from S004.1.
- [ ] A finished multiplication task is a pass.
