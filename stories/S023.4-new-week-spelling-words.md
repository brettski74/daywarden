Title: Set up the new week's spelling words
Status: Refined
Story Points: 21
Last Updated: 2026-11-08 19:45:00

# User Voice

As a parent, I want to type in next week's spelling words, record all of them in one go, review the clips, and apply
the list, so that the weekly change takes ten minutes in the browser and last week's words go to revision by
themselves.

# Use Cases

## UC1 - Start the new week

- The spelling page from S023.2 has a "New week's words" button in its context bar. It opens
  `/parent/tasks/<name>/week`, a portal page with its own address.
- A setup in progress is kept on the service. Opening the page again, or reloading it, carries on where the parent
  left off. There is one setup in progress for each spelling task.

## UC2 - Enter the list

- The parent types the week's words, one per line, and presses Check.
- A line may be a plain word, such as `read`, or a homograph key, such as `read.1`. Spaces either side are ignored. A
  blank line is ignored.
- A line that is not a valid name is refused with the same rule as the pools: letters, `-`, and `'`, up to 22
  characters, with an optional `.<n>`. So is a word listed twice, ignoring case.
- The service checks each word against the task's current pool, revision pool, and attic, and reports where it already
  is and whether it already has a word clip and a sentence clip.
- A plain `read` that matches homographs already in the pools, such as `read.1` and `read.2`, is flagged. The parent
  picks which of them belong to the week, or adds a new number.

## UC3 - The week's list

- The week's words are listed in the same layout as the spelling word list: the word, where it is now (New, Current,
  Revision, or Attic), whether it has a word clip, whether it has a sentence clip, and the recording buttons from
  S023.3.
- Clicking a word or sentence that has a clip plays it.
- Each row has a box for a sentence using the word. The text is only a prompt for the speaker. It is kept with the
  setup in progress, survives a reload, and is thrown away on Apply or Cancel. It is never written to a policy or
  data file.
- The parent can edit a word in the list, for example changing `read` to `read.1` after hearing that the existing
  `read` is the other meaning.

## UC4 - A new homograph

- The pools have a plain `read`, and the parent changes the week's `read` to `read.1` for a new meaning. On Apply,
  the new word is `read.1`, and the existing `read` takes the next free number, `read.2`, with its sentence clip renamed
  to match.

## UC5 - Record the whole week in one take

- "Record all" opens a recording dialog with a prompt listing, one line for each clip, every word followed by its
  sentence text. A word with an empty sentence box has only its word line.
- "Record missing" lists only the pieces that have no clip yet: the word line for a word with no word clip, the
  sentence line for a word with no sentence clip and a sentence typed, or both. Words with every piece recorded are
  left out.
- Recording starts on any key and ends on Enter, with nothing to type in between, as in S023.3.
- The service cuts the take, and the clips are assumed to be in the same order as the prompt lines.
- Review uses the S023.3 controls, stepping through prompt lines and clips together. The dialog shows the line
  expected, such as "3 of 18: rope (sentence)", and plays each clip as it comes up:
  - **Keep:** the clip is the expected line. Move to the next line and the next clip.
  - **Junk:** the clip is noise. Discard it and play the next clip, still expecting the same line.
  - **Discard:** the clip is the expected line, or part of it, but it is poor or badly cut. Discard it and move to the
    next line and the next clip.
  - **Missing:** the expected line was not said, was not picked up, or ran into the clip before it. Move to the next
    line, staying on this clip.
  - **Replay** and **Back**, with the same keys, as in S023.3.
- When the clips run out before the lines, the remaining lines stay unrecorded. When the lines run out first, the
  dialog says how many clips were left over.
- When review ends, the list is updated to show which words now have a word clip and a sentence clip.

## UC6 - Apply or cancel

- Kept clips stay pending with the setup. Nothing in the pools changes until Apply.
- Apply stays disabled, saying which words still need a word clip, until every word in the list has one. A missing
  sentence clip does not block Apply.
- Apply, in one step:
  - moves every word now in Current that is not on the week's list into Revision;
  - moves each listed word in Revision or the Attic into Current;
  - writes each new word, and each kept clip for an existing word, into Current, replacing any older clip of that kind;
  - renames an existing homograph as in UC4.
- When the new pools would not load with the task's `current_required` or `revision_required`, Apply is refused with a
  message, as in S023.2, and the page offers to change the target in the same step.
- After Apply, the page goes to the spelling page, and the status bar says how many words became current and how many
  went to revision.
- Cancel asks for confirmation, then throws away the setup, its pending clips, and its sentence text. The pools are
  unchanged.

# Acceptance Criteria

- [ ] "New week's words" on the spelling page opens `/parent/tasks/spelling/week`. Reloading it keeps the list, the
      sentence text, and the clips kept so far.
- [ ] Checking a list of three new words, one current word, one revision word, and one attic word shows each with
      where it is now and whether it has word and sentence clips.
- [ ] A line such as `don't` is accepted. A line such as `rope2`, `two words`, or a word listed twice is refused with a
      message naming the line.
- [ ] A plain `read`, when the pools have `read.1` and `read.2`, is flagged and asks which of them to use.
- [ ] Changing `read` to `read.1` when the pools have a plain `read`, then applying, leaves `read.1` as the new
      recording in `spelling/current`, and the old recording and its sentence as `read.2`.
- [ ] Record all shows each word on its own line, followed by its typed sentence on the next line, and skips the
      sentence line for a word with no sentence text.
- [ ] Record missing shows only the lines with no clip: a word with a word clip and no sentence shows only its
      sentence line, and a word with a sentence clip and no word clip shows only its word line.
- [ ] Recording starts on any key and stops on Enter. A key pressed during the recording, other than Enter, does
      nothing.
- [ ] In review, a clip of background noise marked Junk keeps the same expected line and plays the next clip.
- [ ] A poor clip marked Discard moves on to the next line and the next clip, and that line is still unrecorded.
- [ ] A line that was skipped while speaking, marked Missing, moves to the next line, and the same clip is offered for
      it.
- [ ] Back undoes the last decision. The keys K, J, D, M, R, and B work as the buttons do.
- [ ] After review, the list shows the new word and sentence clips. Clicking them plays the kept clips.
- [ ] Apply is disabled while a listed word has no word clip, and says which ones. It is enabled when every word has a
      word clip, even with some sentences missing.
- [ ] Apply moves last week's current words to `spelling/revision`, moves listed revision and attic words into
      `spelling/current`, and writes the new clips into `spelling/current`. The next spelling run asks exactly the
      week's words as current words.
- [ ] Before Apply, the files in `spelling/current`, `spelling/revision`, and `spelling/attic` are unchanged, however
      many clips have been kept.
- [ ] Cancel, once confirmed, leaves the pools unchanged, and opening "New week's words" again starts an empty list.
- [ ] A week list shorter than `current_required` is refused at Apply with a message. Lowering the target on the page
      lets Apply go through, and the task's `current_required` in its policy file is updated.
- [ ] A single row's re-record buttons work in the week list as they do on the spelling page, but the kept clip stays
      pending with the setup until Apply.

# Notes

Depends on S023.2 and S023.3.

- The setup in progress, its list, its sentence text, and its pending clips are kept in a hidden directory under the
  data directory, with the pending clips beside a small state file, so Apply is a set of renames on one file system.
- Apply moves files in an order that can be undone. If a move fails partway, the moves already made are reversed, the
  page reports the error, and the setup in progress is kept.
- Apply uses the same move and policy check as a pool change saved on the spelling page in S023.2, and the same
  rewrite of the task's file, hand-edit check, and config history commit when a target is changed.
- A word already current and on the list stays current. Re-recording it here replaces its clip only on Apply.
- The parent session's idle limit applies here as in S023.3. A take refused because the session ended is kept in the
  page for Upload after signing in again.
