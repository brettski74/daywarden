# User Voice

As a parent, I want to change bedtime, the evening window, the revision requirement, and the YouTube quota without redeploying the service.

# Use Cases

- Add, rename, and remove clients and their source IPs.
- Set the household timezone.
- Add and remove site groups, set their priority, mark the single default group, and edit their patterns.
- Edit a group's ordered rules: condition, weekday windows, revision count, and the true and false actions, including the deny message.
- Set or clear a group's daily time quota as a duration in seconds, minutes, or hours, and set the bucket length separately. Saving a new bucket length does not change the stored quota.
- Saving an unconditionally allowed group updates the proxy bypass list so those hosts still work when the policy service is down.

# Acceptance Criteria

- [ ] A change to a time window changes the next decision for a matching URL, with no restart beyond what the story documents. A restart is acceptable if the story says so and the parent page tells the parent it happened.
- [ ] Invalid configuration is refused and the previous configuration remains in force. This includes two default groups, two groups with the same priority, a window whose start equals its end, and a negative quota.
- [ ] The sample household policy can be reproduced through the pages, then saved, then loaded again showing the same rules.
- [ ] Removing the default group is either refused or clearly results in unknown URLs being denied. The page says which.
- [ ] After a save, the addon bypass list includes every host pattern from groups whose only rule is an unconditional allow, plus the task site. A Classroom host added in the page is bypassed on the next proxied request after the addon has reloaded the list.
- [ ] The child cannot reach these pages without the parent session from S007.1.

# Notes
