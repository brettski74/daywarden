# User Voice

As a parent, I want to change bedtime, the evening window, the revision requirement, and a child's quota without redeploying the service.

# Use Cases

- Add, rename, and remove client groups and their addresses.
- Add and remove site groups, set their priority, and edit their patterns. There is no control that marks a group as the default. `default` is the remainder and is not editable as a group.
- Add and remove time windows and their periods, including a weekday range and an end suffix `+n`.
- Add and remove quotas, set the time limit, the byte limit, the grace, and the rule set that decides what accrues.
- Edit named rule sets: the ordered rules, the condition, the condition's names, and the true and false actions. An omitted action is stored as continue. `evaluate` names a rule set or holds an inline list.
- Set the household timezone, `entry`, the revision-task URL, the bucket length, and the household grace defaults.
- Saving writes a policy the loader in S008.1 will accept, and the next decision uses it. A restart is acceptable if the page says that it happened.

# Acceptance Criteria

- [ ] A change to a time window changes the next decision for a matching URL, with no restart beyond what this story's page tells the parent.
- [ ] Invalid configuration is refused and the previous configuration remains in force. This includes a group named `default`, two site groups with the same priority, the same address in two client groups, a negative grace, an unquoted or otherwise illegal clock, a missing `entry`, and both `day` and `days` on one period.
- [ ] A period whose start clock equals its end clock is saved as a 24-hour period. It is not rejected.
- [ ] The household policy from S008.5 can be reproduced through the pages, then saved, then loaded again showing the same rules.
- [ ] The pages do not offer a default-group flag, a weekday task-count override, or a quota stored on a site group. A byte size is entered with `b`, `k`, `M`, `G`, or `T`.
- [ ] Saving does not rewrite the proxy bypass list.
- [ ] The child cannot reach these pages without the parent session from S007.1.
