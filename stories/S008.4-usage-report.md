Title: Report usage by group and quota

Last Updated: 2026-10-26 00:49:00

# User Voice

As a parent, I want to see usage for a site group, a client group, or a quota, so that Classroom, an unknown computer, and the YouTube limit are each visible.

# Use Cases

- Choose a site group, a client group, or a quota.
- A site-group or client-group view shows the day's buckets, the time they represent, the clock times, and the bytes.
- A quota view is per client group. Opening a quota without a client group shows each client group's balance for it.
- `default` is a selectable group for both site and client. A quiet day is an empty day, not an error.

# Acceptance Criteria

- [ ] After observations have marked buckets, the site-group page shows them on the correct local day for that client group and site group, including a group that no quota accepts.
- [ ] The same buckets are reachable from the client-group view.
- [ ] A quota page shows that client group's ended time against the time limit and the stored bytes against the byte limit. A limit of zero is shown as zero, not hidden.
- [ ] Selecting a quota with no client group lists every client group that has a balance, including `default`.
- [ ] A day with no traffic is shown as no usage.
- [ ] Times are in the household timezone. Byte totals for each bucket are still visible.
- [ ] The page keeps the parent barrier from S002.2. The child cannot open it with no barrier.
