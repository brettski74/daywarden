# User Voice

As a child, I want to pick a word out of the sentence and drop it on the part of speech I think it is, and I want to move it again if I change my mind.

# Use Cases

- The sentence is shown in large text at the top centre.
- Under it is a table. The narrow left column names each part of speech the task asks for. The wide right column holds the words he has dropped there.
- Dragging a word in the sentence drags a copy that starts lined up on that word. The word in the sentence stays where it is.
- If that word already has a copy in the table or in mid-drag, a second copy is not created.
- Dropping the copy in a right-hand cell appends it to a comma-separated list in that cell. It does not sit at the pixel where it was dropped.
- Dropping the copy outside the right-hand column animates it back to its word in the sentence, where it merges away.
- A word already in a cell can be dragged to another cell.
- A large Submit button at the bottom sends the sentence to be scored. The quiz then shows the next sentence, or the final result when the list is finished.
- "Try a different task" abandons the attempt as in S003.2.

# Acceptance Criteria

- [ ] The sentence text never loses a word because it was dragged.
- [ ] Each occurrence has at most one copy outside the sentence.
- [ ] A copy dropped in a cell appears in that cell's comma-separated list.
- [ ] A copy dropped outside the right-hand column returns to its sentence word and is no longer in the table.
- [ ] Moving a word from one cell to another removes it from the first list and appends it to the second.
- [ ] Submit sends the placements the child can see, and the score on screen matches the score S006.1 computes for those placements.
- [ ] After the last sentence, the page tells him whether the quiz was passed and, if not, that it did not count toward today's revision.
- [ ] The interaction works with a pointer. Keyboard access for placing a word is included if it can be done without a second, conflicting control scheme; if it cannot, the story notes the limitation rather than shipping a broken keyboard path.
- [ ] The flow is checked in a browser: drag, move between cells, drop outside, submit, and see the result. A screenshot of the resting page is not enough.
