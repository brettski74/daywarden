# User Voice

As a parent, I want to see how much time was spent on Classroom and on YouTube, and when, so that I can tell whether the limits match real use.

# Use Cases

- Open a page, choose a client and a site group, and see recent days.
- Each day shows the counted buckets, the time those buckets represent, and the clock times they covered.
- The page works for a group that has no quota, such as school work.

# Acceptance Criteria

- [ ] After observations have marked buckets, the page shows those buckets on the correct local day for that client and group.
- [ ] A day with no traffic is shown as no usage, not as an error.
- [ ] The times displayed are in the household timezone.
- [ ] The page is only available to a signed-in parent once S007.1 exists. Until then it is acceptable to protect it with the same temporary password mechanism S007.1 will replace, or to bind it to a note in the story that it must not be left open to the child. The story is not done if the child can open the report with no barrier at all.
- [ ] Byte totals for each bucket are visible, so we can later judge whether a volume cap is worth building.
