# User Voice

As a parent, I want daywarden's own browser extension on the children's computers to report each page they view, and
to see those page views in the parent pages, so that I can see what was watched and read on sites that change pages
without loading them.

# Behaviour

The checks below are the expected outcome. Their details are settled when this story is refined from S034.1's
findings.

## Install

- [ ] daywarden provides the extension for the browsers S034.1 recommends, and `docs/child-computer.md` explains how to
  force-install it by browser policy so that the child cannot remove or disable it.

## Page views

- [ ] Each page a child's browser shows is recorded with the computer's address, client group, full address, title,
  and time, including a change of address without a page load. Clicking from video to video on YouTube records one
  page view per video.
- [ ] A signed-in parent can list page views with the client group, date range, and host filters of the S030.3
  Requests page.
- [ ] Page views are kept for a set time, set in the policy file as `request_retention` is.

## Missing extension

- [ ] daywarden notices a computer that makes browser requests but sends no page views, and tells the parent.
