# User Voice

As a child, I want to be asked to add two numbers in my head, so that I can finish a revision task by getting enough of them right.

# Use Cases

- The question displays `m + n =`.
- The expected answer is `m + n`.

# Acceptance Criteria

- [ ] A drawn pair of 6 and 7 displays `6 + 7 =` and accepts 13 as the only correct answer.
- [ ] The task uses the shell from S004.1, including weights, shrinking timer, sounds, and the give-up control.
- [ ] A finished addition task is a successful revision attempt.
