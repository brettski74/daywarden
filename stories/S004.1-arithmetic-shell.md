# User Voice

As a child, I want one question in the middle of the screen, a box that is ready for my answer, and a bar that shows how much time I have left, so that I can practice without hunting around the page.

# Use Cases

- The task configuration includes a list of integers, each with a positive integer weight, a maximum timeout, a minimum timeout, and the number of correct answers required.
- Each question draws two values, `m` and `n`, independently from that weighted list.
- The question is shown in very large text in the centre of the screen. Under it is a moderately large text box, focused when the question appears.
- A timer bar at the bottom shows the time remaining for this question.
- Enter submits the contents of the box.
- A correct answer scores one point, shows that it was correct, and plays the correct sound.
- An incorrect answer does not change the score, shows the right answer, and plays the incorrect sound.
- If the timer reaches zero, a box that already holds the right answer is treated as correct. An empty or wrong box is a timeout: same as incorrect, but the time's-up sound plays instead.
- The next question appears after the feedback. The session continues until the correct-answer count reaches the required number. There is no failure count.
- "Try a different task" uses the give-up behaviour from S003.2.
- After `k` correct answers, with `N` required and `N > 1`, the next timeout is `Tmax * (Tmin / Tmax) ^ (k / (N - 1))`. It is `Tmax` at `k = 0` and `Tmin` at `k = N - 1`. When `N` is 1, the timeout is `Tmax`.

# Acceptance Criteria

- [ ] With weights 5 for 1, 7 for 2, 5 for 10, and 10 for each integer from 3 to 9, a large sample of draws falls inside that distribution. A test checks the frequencies within a stated tolerance, not a single draw.
- [ ] A weight of zero or a negative weight is rejected as invalid configuration. A positive weight is accepted.
- [ ] The operand list is not limited to the integers 1 through 10. A configured value of 12 can appear.
- [ ] The input is focused when the question is shown.
- [ ] Submitting the right answer increases the correct count by one and plays the correct sound.
- [ ] Submitting a wrong answer leaves the correct count unchanged, shows the expected answer, and plays the incorrect sound.
- [ ] When the timer expires with the right answer already in the box, it counts as correct.
- [ ] When the timer expires with an empty or wrong box, it counts as a timeout and plays the time's-up sound, which is a different file from the incorrect sound.
- [ ] None of the three sounds is a spoken "correct", "wrong", or "time's up".
- [ ] With `Tmax` 10 seconds, `Tmin` 4 seconds, and 5 correct answers required, the first question has 10 seconds and the question after 4 correct answers have 4 seconds. The timeouts in between follow the formula.
- [ ] Reaching the required number of correct answers marks the attempt successful and increments today's revision count.
- [ ] Wrong answers never mark the attempt failed.
- [ ] The page is usable from the keyboard: type an answer, press Enter, see the next question.
