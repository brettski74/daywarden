# User Voice

As a parent, I want one shared pool of sorted sentences that several parts-of-speech tasks can draw from with
different filters, timeouts, and pass marks, so that I do not have to copy the same sentences into a new task every
time he needs a different mix of practice.

As a child, I want each run to ask unseen sentences until I pass or the run ends, with harder sentences getting more
time when the parent says they are harder, so that a long sentence is fair and a revision task can still be quicker.
