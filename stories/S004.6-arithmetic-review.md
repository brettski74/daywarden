# User Voice

As a parent, I want an arithmetic attempt to show me at a glance how he went and which facts slowed him down, so that I can see whether he is answering from memory or still working them out.

# Use Cases

- Opening an arithmetic attempt in the S003.3 review shows a summary above the question list:
  - counts of correct answers, incorrect answers, and timeouts in the current run
  - his average time per correct answer in the current run, in seconds to one decimal place
  - the target, such as "20 required", and the operation
- Below the summary, a table lists the current run's questions in order. Each row shows the question with the expected answer, such as `6 + 7 = 13`, his answer, the outcome, the time he took, and the time allowed.
- An incorrect answer or a timeout stands out from a correct answer, by more than colour alone.
- An expired run from S004.1 is listed after the current run, under its own heading with the time it expired. It has the same summary and table. It does not count toward the current run's summary.
- An attempt still in progress shows the same view, with the questions so far.
- A non-arithmetic attempt is shown as S003.3 already shows it.

# Acceptance Criteria

- [ ] An attempt with 20 correct answers, 3 incorrect answers, and 2 timeouts shows those three counts in the summary.
- [ ] The average time per correct answer is the mean of the correct answers' times only. Incorrect answers and timeouts are left out.
- [ ] Each question row shows the question with the expected answer, his answer, the outcome, the time taken, and the time allowed. An empty answer is shown as empty, not as zero.
- [ ] Incorrect answers and timeouts are distinguishable from correct ones without relying on colour.
- [ ] An attempt with an expired run lists the current run first and the expired run after it under its own heading. The expired run's questions are not counted in the current run's summary.
- [ ] An in-progress arithmetic attempt shows the summary and the questions so far.
- [ ] A `parent_check` attempt and an attempt of another type still show as S003.3 shows them.
- [ ] The view stays behind the parent session from S007.1, like the rest of S003.3.

# Notes

Depends on S004.1 for the attempt record and on S003.3 for the review page. Before this story, the raw arithmetic record is readable through the S003.3 view. A "slowest facts" breakdown across attempts is out of scope.
