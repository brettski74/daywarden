# User Voice

As a parent, I want to put websites into named groups with a priority order, so that Classroom is recognized before a general Google rule, and so that everything else falls into a default group.

# Use Cases

- Create any number of groups. Each group has a unique priority. Lower priority is tested first.
- A group has a list of glob patterns.
- A pattern containing `://` is matched against the absolute URL with the fragment removed.
- A pattern without `://` is matched against the host only, so `*.youtube.com` and `youtu.be` work.
- Matching is case-insensitive. `*` matches across slashes. `?` matches one character.
- Exactly one group may be marked as the default. It is used only when no earlier group matches. Its patterns are ignored.
- A request that matches nothing, when no default group exists, is denied.

# Acceptance Criteria

- [ ] For a URL that matches two groups, the lower priority number wins.
- [ ] `https://classroom.google.com/u/0/h` matches `https://classroom.google.com/*` and `classroom.google.com`.
- [ ] `https://www.youtube.com/watch?v=abc#t=10` matches `*.youtube.com` and does not use the fragment.
- [ ] `https://www.youtube.com/watch?v=abc` does not match `*.googlevideo.com`.
- [ ] Host matching ignores case in both the URL and the pattern.
- [ ] Two groups with the same priority are rejected as invalid configuration.
- [ ] Two default groups are rejected as invalid configuration.
- [ ] With a default group present, an unrecognized URL is assigned to it.
- [ ] With no default group, an unrecognized URL produces a deny decision with a message that says the site is not in a configured group.
- [ ] Groups are stored in SQLite and loaded again after a restart.
