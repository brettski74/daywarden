Title: Run mitmproxy with a local CA

# User Voice

As a parent, I want one command to start the proxy with a stable certificate authority, so that I install the CA on my child's computer once and it survives restarts.

# Use Cases

- Start the stack from the repository with Docker Compose.
- The proxy listens as an explicit HTTP proxy on a configured port.
- The CA key and certificate live in a volume. A new container does not mint a new CA if that volume already has one.
- A parent can copy the CA certificate out of the project as a PEM file. Both children's computers run Arch Linux. Installing that file into an Arch trust store is S000.4, not this story.

# Acceptance Criteria

- [x] `docker compose up` starts mitmproxy in regular (explicit) proxy mode.
- [x] The CA certificate and key are created on first start and reused on the next start.
- [x] An HTTP request through the proxy reaches the origin and the response comes back, before any authorization addon is installed.
- [x] An HTTPS request through the proxy succeeds when the client trusts the CA, and fails with a certificate error when it does not. That check may use a local client such as `curl`. It does not have to be run on the child's computer.
- [x] The exported CA is a PEM file, which is what Arch's trust store accepts. This story does not install it on Arch and does not document Windows or macOS trust steps.
- [x] The listen port and the CA volume path are configuration, not hard-coded constants in a script that a parent would have to edit in two places.

# Notes

Depends on nothing else. Does not call the policy service yet. The proxy host is whatever machine runs Docker Compose. It is not assumed to be one of the Arch computers.

`docker compose up` uses mitmproxy 12.2.3 in regular mode. `PROXY_PORT` and `CA_VOLUME_PATH` live in `.env`. The PEM to copy is `mitmproxy-ca-cert.pem` inside that directory. `mitmproxy-ca.pem` is the private key and stays there. `python -m pytest` covers the acceptance checks, including a container whose CA directory is owned by a group the image does not already know.
