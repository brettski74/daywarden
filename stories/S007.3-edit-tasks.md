# User Voice

As a parent, I want to set this week's spelling words, the arithmetic weights, and the parts-of-speech sentences, and I want to decide which client group receives which task.

# Use Cases

- Create and edit a task of each type the service knows: `parent_check`, addition, subtraction, multiplication, division, spelling, and parts of speech.
- Edit the fields those stories define: weights and timeouts, word pools and weekday targets, sentences and pass marks, pass cooldown, and failure cooldown.
- Edit `available_from`, `due_date`, `max_skips`, and `max_passes` from S003.1 on every child-facing task type. `parent_check` does not offer those fields.
- Assign or unassign a task for a client group, including `default` when the parent wants unknown machines to receive a task.
- Saving a task that has a `due_date`, when one or more client groups already have a pass for it, warns the parent before anything is written. The warning names those groups and says that this save does not ask them to do the task again. A group with no pass still follows the due date. New work for a group that has already passed is a new task. Confirming the warning writes the edit. Cancelling leaves the stored task unchanged.
- For spelling, upload audio or start the generator from S005.4 when that story is done. Before S005.4, upload is enough.

# Acceptance Criteria

- [ ] A task created here and assigned to a client group is eligible for every address in that group under the rules of S003.1, and is not eligible for a different group.
- [ ] Unassigning a task stops it being offered to that client group. Existing attempt history remains readable.
- [ ] An arithmetic task edited so that it requires a different number of correct answers uses the new number on the next attempt. An attempt already in progress keeps the number it started with.
- [ ] A spelling list edited here is the list the next spelling attempt uses. A weekday word target edited here stays on the spelling task. It does not become a `tasks_required` override.
- [ ] A parts-of-speech sentence edited here is the sentence the next attempt uses.
- [ ] Invalid quiz configuration is refused with a message that says what is wrong, and the stored task is unchanged. Examples: a division operand list containing zero, a this-week target larger than the pool, a parts-of-speech sentence with no categories, a `due_date` or `available_from` that is not a date, a negative `max_skips`, a negative `max_passes`.
- [ ] `available_from`, `due_date`, `max_skips`, and `max_passes` saved here are the values S003.1 uses for that task. Clearing a field turns that rule off.
- [ ] Saving a parts-of-speech task that already has a `due_date` and a pass for the younger group warns, names that group, and does not write until the parent confirms. A task with no `due_date` saves without that warning. Cancelling the warning leaves the previous sentences in place.
- [ ] The child cannot reach these pages without the parent session from S007.1.
