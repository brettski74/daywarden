# User Voice

As a parent, I want to change the arithmetic weights, the skip-counting settings, and the parts-of-speech sentences
from the parent portal, as S023 lets me do for spelling.

# Use Cases

- The task pages, the common settings, saving, and the spelling administration are S023. This story is what is left:
  the type-specific area under the divider for `arithmetic`, `skip_counting`, and `parts_of_speech` tasks.
- Edit the fields those stories define: arithmetic weights, operands, and timeouts; skip-counting settings; and
  parts-of-speech sentences, their categories, and pass marks.
- Create and delete tasks, and assign or unassign them to client groups, including `default`. A new task is written to
  its own file in a `tasks/` subdirectory of the config directory, which the root `policy.yaml` includes as a
  directory.

# Acceptance Criteria

- [ ] An arithmetic task edited so that it requires a different number of correct answers uses the new number on the
      next attempt. An attempt already in progress keeps the number it started with.
- [ ] A parts-of-speech sentence edited here is the sentence the next attempt uses.
- [ ] Invalid quiz configuration is refused with a message that says what is wrong, and the stored task is unchanged.
      Examples: a division operand list containing zero, or a parts-of-speech sentence with no categories.
- [ ] A task created here and assigned to a client group is eligible for every address in that group under the rules
      of S003.1, and is not eligible for a different group. It is written to `tasks/<name>.yaml` in the config
      directory.
- [ ] Unassigning a task stops it being offered to that client group. Existing attempt history remains readable.
- [ ] The child cannot reach these pages without the parent session from S007.1.
