# User Voice

As a parent, I want to set this week's spelling words, the arithmetic weights, and the parts-of-speech sentences, and I want to decide which child receives which task.

# Use Cases

- Create and edit a task of each type the service knows: `parent_check`, addition, subtraction, multiplication, division, spelling, and parts of speech.
- Edit the fields those stories define: weights and timeouts, word pools and weekday targets, sentences and pass marks, success cooldown, and failure cooldown.
- Assign or unassign a task for a client IP.
- For spelling, upload audio or start the generator from S005.4 when that story is done. Before S005.4, upload is enough.

# Acceptance Criteria

- [ ] A task created here and assigned to a client IP is eligible for that IP under the rules of S003.1.
- [ ] Unassigning a task stops it being offered to that client. Existing attempt history remains readable.
- [ ] An arithmetic task edited so that it requires a different number of correct answers uses the new number on the next attempt. An attempt already in progress keeps the number it started with.
- [ ] A spelling list edited here is the list the next spelling attempt uses.
- [ ] A parts-of-speech sentence edited here is the sentence the next attempt uses.
- [ ] Invalid quiz configuration is refused with a message that says what is wrong, and the stored task is unchanged. Examples: a division operand list containing zero, a this-week target larger than the pool, a parts-of-speech sentence with no categories.
- [ ] The child cannot reach these pages without the parent session from S007.1.

# Notes

Depends on S007.1, S004, S005.1, and S006.1. Not part of the initial build. Until this story is done, the parent edits task definitions and assignments in config files, and points spelling words at WAV files they recorded. The story is done when all of the types above are editable in the browser.
