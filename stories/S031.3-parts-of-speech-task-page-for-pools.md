# User Voice

As a parent, I want a parts-of-speech task page that picks one or more parts-of-speech pools, sets a parts-of-speech
filter, and sets minimum questions, maximum questions, and correct answers required, so that I can make a
nouns-and-verbs drill and a fuller revision task from the same pools without editing sentences on the task.

# Behaviour

## The page

For a `parts_of_speech` task, `/parent/tasks/parts_of_speech/<name>` no longer embeds the sentence editor. Sentences
are edited under Asset Administration › Parts of Speech Pools (S031.2).

- [ ] Below the common task fields and the divider, the page shows Timeout, Correct Answers Required, Minimum
      Questions, Maximum Questions, the Parts of speech filter, and the Pools control. Labels' titles are the field
      names as elsewhere.
- [ ] Empty Timeout shows `90s` as its placeholder.
- [ ] Empty Correct Answers Required, Minimum Questions, and Maximum Questions show the defaults from S031.1 for the
      current runnable size (from the pools now chosen on the page), in the same light placeholder style other fields
      use, and follow the chosen pools as they change. Maximum Questions' placeholder is that size.
- [ ] The status bar says how many pools are selected and the runnable size, such as "2 pools. 24 sentences."
- [ ] Save, Ctrl+S, the unsaved-changes prompt, and refusal after a hand edit work as in S023.2.

## Pools

- [ ] Pools is a multi-select of every available parts-of-speech pool by user-visible name, including pools not yet
      referenced by any task. Choosing and clearing pools is an edit. A link or equivalent control opens the selected
      pool's Parts of Speech Pools page in a way that keeps unsaved task edits behind the leave prompt when followed
      in this tab.
- [ ] No pool selected is a problem that blocks Save, with a message under the control. Save's title explains it.
- [ ] New task (S027): once a parts-of-speech name and type are locked in, the same Pools control and settings appear,
      and Save writes a task that names the chosen pools.

## Parts of speech filter

- [ ] The filter is an ordered list of part names the parent can add, remove, and reorder. Empty means the task omits
      `parts_of_speech` and each sentence uses its own parts. When set, every name is written on save, tidied as row
      names are in S007.3.
- [ ] An empty name, a name over 20 characters, or two names that differ only in case are problems that block Save.
      A name that is not a recognized part of speech warns as in S007.3 but still allows Save.

## Saving

- [ ] Saving writes `timeout`, `pools`, `parts_of_speech` when the filter is non-empty, and the three question fields
      when set. Clearing a field that has a default removes it from the file so the default applies. A value that would
      fail S031.1's load rules is refused and nothing is written, with the reason in the status bar.
- [ ] The child's next run uses the saved pools, filter, difficulties, and targets. A run in progress keeps what it
      started with, as in S031.1.

## Docs

- [ ] `docs/hierarchical-policy.md` and the README describe choosing pools and the filter from the task page.
      `docs/parent-portal.md` says the parts-of-speech task page no longer edits sentences inline.

# Notes

Depends on S031.1 and S031.2. The multi-select can follow the Client Groups control's patterns from S023.2, with links
to Asset Administration for edit-in-place of a pool.

Out of scope: creating a pool from the task page without going through Assets, weighted pools, and spelling Assets.

Sizing: 13. Settings and placeholders are about 5. Pool multi-select, filter ordering, new-task wiring, and save
refusals are about 8.
