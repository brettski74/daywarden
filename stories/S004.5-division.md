# User Voice

As a child, I want division questions that are the inverse of the multiplication facts I am learning, shown with a proper division sign.

# Use Cases

- The task body sets `operation: division`.
- Draw weighted `m` and `n` as the shell does.
- Let `x = m * n`.
- Display `x ÷ m =`, using the division sign `÷` (U+00F7).
- The expected answer is `n`.

# Acceptance Criteria

- [ ] A draw of `m = 6` and `n = 7` displays `42 ÷ 6 =` and accepts 7 as the only correct answer.
- [ ] The character on screen is `÷`, not `/`.
- [ ] `m` is never zero. A zero in the list `m` is drawn from, as a `value` or inside a `from`/`to` range, is rejected for a division task, because the question would divide by `m`. That list is `first` when it is set, and `operands` when it is not.
- [ ] With `first` set and free of zero, a zero in `operands` is accepted. It only ever becomes `n`, so the question is `0 ÷ m =` with 0 as the answer.
- [ ] With `first` set to the single value 7, every question divides by 7: `(7 × n) ÷ 7 =`, with `n` as the answer.
- [ ] The task uses the shell from S004.1.
- [ ] A finished division task is a pass.
