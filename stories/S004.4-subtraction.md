# User Voice

As a child, I want subtraction questions that are the inverse of the addition facts I am learning, so that I practice the same number pairs from the other direction.

# Use Cases

- The task body sets `operation: subtraction`.
- Draw weighted `m` and `n` as the shell does.
- Let `x = m + n`.
- Display `x − m =`.
- The expected answer is `n`.

# Acceptance Criteria

- [ ] A draw of `m = 6` and `n = 7` displays `13 − 6 =` and accepts 7 as the only correct answer.
- [ ] The weights apply to `m` and `n`, not to the displayed minuend. A test with a heavily weighted addend shows that addend appearing as `m` or as the expected answer, rather than the large sum being drawn directly.
- [ ] With `first` set to the single value 7, every question takes 7 away: `(7 + n) − 7 =`, with `n` as the answer.
- [ ] The task uses the shell from S004.1.
- [ ] A finished subtraction task is a pass.

# Notes

Depends on S004.1. The minus sign on screen may be the Unicode minus `−` (U+2212). A hyphen-minus is not the goal if the minus glyph is available in the chosen font.
