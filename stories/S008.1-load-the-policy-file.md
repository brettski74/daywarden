# User Voice

As a parent, I want the household policy in files I can split by child, so that a nested rule is written once and rejected loudly when a name is wrong.

# Use Cases

- Load one YAML document, including files and one directory level of `*.yaml` and `*.yml` in lexicographic order.
- Define site groups, client groups, time windows, quotas, and rule sets. Each name is unique in its own namespace. The same spelling may be used in two namespaces.
- `entry` names the rule set where access decisions will start. It is required.
- A file already loaded is skipped. An include cycle is not an error. An `evaluate` cycle is.
- DNS names on client groups are resolved at load. A name that fails keeps the addresses from the last successful load.

# Acceptance Criteria

- [ ] A missing `entry`, an unknown reference, a second definition of the same name, a duplicate key, and a YAML anchor or alias each fail the load. The previously stored policy stays in force.
- [ ] A household setting or a named entity may appear in an included file. A second copy anywhere in the load is an error. A later file does not override an earlier one.
- [ ] `default` is rejected as a site-group name and as a client-group name.
- [ ] Two site groups with the same priority are rejected. Overlapping site patterns are accepted.
- [ ] The same resolved address in two client groups, or twice in one group, is rejected. An IPv4 address and its IPv4-mapped IPv6 form count as the same address.
- [ ] A time-window period accepts `day` or `days`, quoted `HH:MM` or `HHMM`, a weekday range such as `monday-thursday` and `friday-tuesday`, and an end suffix `+n` for a whole number of zero or more. Both `day` and `days`, an empty day list, a range whose ends are the same day, a negative `+n`, and an unquoted clock that YAML has turned into a number are rejected.
- [ ] A quota accepts a time duration such as `2h` and a byte size such as `720b`, `720k`, `720M`, `720G`, or `720T`. The suffixes are case-sensitive. `720MB`, `720m` as a size, and a bare number are rejected. Omitting either limit stores that limit as zero. Grace defaults to five minutes and `1M` when the file and the quota both omit them. A quota's own grace wins. Zero is allowed. A negative grace is rejected.
- [ ] `group` and `groups` are the singular and plural of one list, and so are `window` and `windows`. Specifying both forms, or an empty list, is rejected.
- [ ] A missing root file leaves the stored policy in place. A missing included path, when the root file is present, fails the load.
- [ ] The decision path may still answer from the previous engine until S008.2. This story's tests cover the loader.
