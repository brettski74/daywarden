# User Voice

As a parent, I want the service to generate the word, sentence, and letter recordings from text, so that I can add a spelling list without recording each clip myself.

# Use Cases

- For a word, a parent enters the spelling and a sentence that contains it.
- A local text-to-speech engine writes the word-only file and the sentence file.
- The same engine, or shipped letter recordings, covers a to z, hyphen, and apostrophe.
- A parent can replace any generated file with their own recording. The quiz plays whatever file is stored.

# Acceptance Criteria

- [ ] Generating audio for a word and a sentence produces two files that S005.1 accepts.
- [ ] The generator runs locally. It does not call a network speech API.
- [ ] If the speech engine is not installed, the command says so and writes no files. The spelling task stays invalid until WAV files are provided another way.
- [ ] Replacing a generated file with a recording causes the quiz to play the replacement, confirmed by the file the word's config points at.
- [ ] The documented engine is a specific open-source program and a version known to run on the household machine. The story names it when it is implemented.

# Notes

Not part of the initial build. The parent records the word and sentence clips, which is the easier way to get speech that is slow and clear. Free local engines exist if this story is picked up later: Piper is fast and slightly flat, Kokoro is more natural, and espeak-ng stays intelligible when slowed right down but sounds robotic. Slowing a neural voice tends to smear the consonants a spelling test depends on.

Depends on S005.1. If this is built, it is a local command that writes the WAV files S005.1 already accepts. It does not call a network speech API, and it does not need the quiz builder from S007.3. The quiz in S005.2 does not wait for this story.
