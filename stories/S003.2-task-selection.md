# User Voice

As a child, I want YouTube to send me to a revision task I am allowed to do today, and I want a way to put that task down and try a different one if I am stuck. As a parent, I want "try a different one" not to count as finishing revision.

# Use Cases

- The decision API, when it chooses `revision_task`, returns a `302` to a concrete URL on the task site for this client IP.
- The picker chooses the eligible task whose last success is oldest. A task that has never been completed comes before any task that has. Ties are stable and not dependent on request order in a way that starves one task: equal candidates rotate.
- If no task is eligible, the page says so in plain language and does not redirect in a loop.
- Every task page has a control to try a different task. Using it marks the current attempt abandoned and opens the next eligible task, excluding the one just abandoned in this visit so he does not immediately land on the same task.
- A built-in task type, `parent_check`, shows a short message and does not have a button the child can press to complete it. A parent marks that attempt successful from the parent side. This exists so the gate can be tried before S004.

# Acceptance Criteria

- [ ] With two eligible tasks, one never completed and one completed last week, the picker returns the never-completed task.
- [ ] A request that the rules redirect at 16:00 receives a `302` whose `Location` is a URL on the task site for that chosen task.
- [ ] Completing the `parent_check` task as a parent increases today's success count by one, and a second decision for YouTube then follows the rules with that new count.
- [ ] The child has no request he can send that marks `parent_check` successful.
- [ ] Choosing "try a different task" marks the attempt abandoned, does not increase the success count, and opens a different eligible task when one exists.
- [ ] When the abandoned task was the only eligible one, the page says there is nothing else available right now.
- [ ] The task site's host is on the proxy bypass list, so the quiz pages load after a redirect.
