# User Voice

As a parent, I want to be able to record letters and words for use in spelling quizzes and easily process them into usable audio clips with minimal effort.

I want a script that can take a recording in a suitable audio format such as .wav, .mp3, .opus or .m4a, cut it into separate clips, removing the silence in between with a small 100ms guard section before and after the relevant speech and with those 100ms guard sections faded in and out so that the clips can be cleanly re-assembled for playback later without introducing any harsh cuts in the audio output.

As an example, I have recorded myself speaking the entire alphabet plus dash and apostrophe with a second or two of silence in between. I want to cut that up into 28 separate sound files with minimal leading and trailing silence and that collapses to zero at the beginning and end to avoid harsh cuts during playback.

I believe that the python library pydub should be an excellent tool for achieving this.

We should build this in a way that the workflow can be re-used in the web UI in the future. For now, a script that I can run from the command line and that prompts for a name for each identified clip as they are found and writes out the processed clip including the fade in/out processing as an opus file using libopus is all that I need for this story. But in a future story, I expect to add the ability to record new spelling lists through the browser UI, so we will eventually want this library to be used by some kind of web page which will allow the user to record their voice saying a list of sentences and/or words and cut them up with 100ms of fade in/out as well and write them into a specified directory on the server, so build this script in a way that the main elements are implemented in a library that can be easily integrated into a web UI workflow as described in the future.
