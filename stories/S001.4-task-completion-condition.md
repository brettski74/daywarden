# User Voice

As a parent, I want entertainment sites to stay redirected until today's revision tasks are finished, so that YouTube comes after schoolwork.

# Use Cases

- A rule condition `tasks_complete` carries a required count, with an optional different count for named weekdays.
- The condition is true when the number of successful revision completions for this client on this local day is greater than or equal to the count that applies today.
- Until S003 records real completions, the count is whatever is stored for that client and day, including a count written by a test or by an administrator.

# Acceptance Criteria

- [ ] A required count of 2 is false when the stored count is 0 or 1, and true when it is 2 or more.
- [ ] A Wednesday override of 1 is used on Wednesday. The default of 2 is used on Thursday when Thursday has no override.
- [ ] The count is per client. Another client's completions do not change this client's result.
- [ ] The count resets when the household date changes. A completion stored for yesterday does not count today.
- [ ] Plugged into the sample schedule from S001.3, a stored count of 2 at 16:00 on Wednesday makes rule 4 continue, and a stored count of 1 at the same time redirects.
- [ ] The condition does not care which task types made up the count. That catalogue arrives in S003.
