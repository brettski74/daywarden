# User Voice

As a parent, I want an Asset Administration section where I create and edit parts-of-speech pools by dragging words
into rows the same way he sorts them, so that shared pools live in one place instead of on a single task page.

# Scenarios

## A new pool for nouns and verbs

The parent opens Asset Administration › Parts of Speech Pools, creates "Year 3 basics", sets difficulty to 1, adds
sentences with Alt+N, sorts nouns and verbs, and saves. The pool appears in the list. A parts-of-speech task can name
it once S031.3 is done; until then `dw check` accepts a hand-written `pools` entry that uses this name.

# Behaviour

## Asset Administration

Asset Administration is a new sidebar group, separate from Attempts, Usage, and Task Administration. This story only
puts Parts of Speech Pools under it. Spelling stays on the spelling task page until S032.

- [ ] The sidebar has an Asset Administration group with a Parts of Speech Pools link to
      `/parent/assets/parts-of-speech-pools`.
- [ ] *Added in implementation:* The portal's built scripts and stylesheets are served from `/parent/build/` instead of
      `/parent/assets/`, so `/parent/assets/...` addresses are portal pages that open on a deep link and Reload. A
      missing file under `/parent/build/` is a 404, and sign-in never returns to `/parent/build/...`.
- [ ] Without a parent session, that address goes to sign-in and returns afterwards. Its data addresses under
      `/parent/api/` answer 401 and never redirect.

## The pool list

- [ ] `/parent/assets/parts-of-speech-pools` lists every available parts-of-speech pool by its user-visible name, with
      its difficulty and how many sentences it has, and a control to create a new pool.
- [ ] Creating a pool asks for a name, makes an empty pool at difficulty 1 at once (or on the first save — one clear
      choice in implementation), and opens its page. A duplicate name is refused with a reason.
- [ ] The list updates after a create, rename, or delete without a full portal reload.

## A pool page

- [ ] `/parent/assets/parts-of-speech-pools/<id>` (or an equivalent stable address) shows the pool's Name, Level of
      difficulty, then the sentence blocks and Add sentence. Editing sentences, rows, sorting with the mouse and
      keyboard, warnings, and problems work as in S007.3's sentence editor, moved here from the parts-of-speech task
      page.
- [ ] Level of difficulty is a number box for 0.5 through 10. Empty shows `1` as its placeholder. A value outside that
      range is a problem that blocks Save.
- [ ] Each sentence block has its own Level of difficulty box, empty meaning "use the pool's", placeholder the pool's
      value as shown on the page. The same 0.5 through 10 bounds apply when set. There is no per-sentence Timeout.
- [ ] Save, Ctrl+S, the unsaved-changes prompt, refusal after a hand edit of a config file, and the config history
      commit work as in S023.2. A good save is checked and applied as any policy save is.
- [ ] Saving writes only changed sentences as in S007.3, tidies part names as in S007.3, and writes difficulty only when
      it differs from the default (pool) or from the pool's value (sentence).

## Rename and delete

- [ ] The pool page can rename the pool. Rename changes the user-visible name. Tasks that already use the pool keep
      using it without the parent editing each task (stable id, or an automatic rewrite of references — either is fine
      when that behaviour holds). A name that clashes is refused.
- [ ] Delete asks for confirmation. Delete is refused while any `parts_of_speech` task names the pool, with a message
      that lists at least one such task. When nothing references it, delete removes the pool and returns to the list.

## Docs

- [ ] `docs/hierarchical-policy.md` describes parts-of-speech pools and that they are edited under Asset
      Administration › Parts of Speech Pools. `docs/parent-portal.md` names the Asset Administration group and those
      pages.

# Notes

Depends on S031.1 for pool shape and load rules, and on S007.3 for the sentence editor behaviour. S031.3 removes that
editor from the task page and adds the pool picker.

The child's quiz page is unchanged in look and drag behaviour beyond what S031.1 already requires. The shared
`word_sort.js` module stays the one shared piece with the portal.

Out of scope: spelling under Assets, pool import/export, and reordering pools on a task (task order does not affect
selection in S031.1).

Sizing: 21. The Asset Administration shell and list/create/rename/delete are about 8. Moving and extending the
sentence editor with pool and per-sentence difficulty is about 13, in line with S007.3's editor effort once the shared
module exists.

## Change Summary

The pool list and pages are a new Asset Administration sidebar group. A pool's address is its file's stable id, such as
`/parent/assets/parts-of-speech-pools/year-3-basics`, so a rename keeps the address. Creating a pool writes it at once,
as `name: <name>` and `sentences: []`, and opens its page; this is the one choice the story left open. An empty pool is
fine while no task names it, and S031.1's "pool with no sentences" load error still applies once one does. Names are
compared without regard to case for create and rename, and are at most 60 characters.

Every pool change goes through `TaskAdmin.change`, so the hand-edit commit, the whole-policy check, the reload of every
service, the version check against a hand edit, and the config history commit are the same code as a task save. To
check a pool before it is written, the loader's `overrides` now reach pool files too. Because an unused pool is not
loaded, a save also runs the pool through the load's own checks (`check_pool`), so a bad sentence is refused even before
a task names it. Rename rewrites the pool's `name` and each `parts_of_speech` task's `pools` list in place with
`task_edit`, as one commit, rather than moving tasks to reference pools by id; the loader and `dw check` stay as S031.1
left them. Delete checks the task files for a reference and refuses with the tasks' names.

The sentence editor moved from the task page to the pool page unchanged apart from Level of Difficulty in place of
Timeout. The task page keeps Timeout and Correct Answers Required and links to the pools; S031.3 replaces that section
with the pool picker and the other settings. A new pool difficulty is written on the line after `name`.

A full test run also exposed problems outside this story's own code, fixed here. The package and installer never
shipped the sentence pools that S031.1's sample tasks name, so a fresh install could not start. The package built its
`env.sample` and `bypass.txt` from this machine's development `.env` and `bypass.txt`, so the package, and every install
and `dw` test built from it, changed with the developer's ports and host names; the package now has fixed sample
values. The observations idle-flow test predated S030.3's end-of-flow report.

The built files moved to `/parent/build/` because the story's addresses are under `/parent/assets/`, which the service
answered with a plain 404 and sign-in refused to return to. This was agreed during implementation.

## Suggested Acceptance Testing

### Acceptance test cases for S031.2

1. **Sidebar, addresses, and sign-in.** Rebuild and start the stack (`dw up`). Open the portal and expand Asset
   Administration: it has Parts of Speech Pools. Open it, then Reload: the page reopens. In a private window open
   `/parent/assets/parts-of-speech-pools/<id>` of a sample pool: sign-in comes back to that page. `curl -k` the
   `/parent/api/parts-of-speech-pools` address without a cookie: 401, no redirect. Confirm the portal's scripts load
   from `/parent/build/` in the browser's network panel. Covers Asset Administration, including the added check.
2. **List and create.** On the list, check each sample pool's name, Level of Difficulty (1 when unset), and sentence
   count. New pool "Year 3 basics": its page opens and `config/parts_of_speech_pools/year-3-basics.yaml` holds
   `name: Year 3 basics` and `sentences: []`, committed as `made parts of speech pool Year 3 basics`. Back on the list it
   is there without a reload. New pool "year 3 BASICS" is refused in the dialog with the reason. Covers The pool list.
3. **The scenario.** On Year 3 basics set Level of Difficulty 1, add sentences with Alt+N, sort nouns and verbs by mouse
   and by keyboard, and Ctrl+S. Check the file and the config history commit. Hand-write a task with
   `pools: [Year 3 basics]` and run `dw check`: it passes. Covers the Scenario and A pool page (editor, save).
4. **Difficulty.** Set the pool to 1.5 and one sentence to 0.5, save: the file has `level_of_difficulty: 1.5` after
   `name` and `0.5` on that sentence. Set a sentence to 1.5 and save: its own line is removed. Set the pool to 1 and
   save: the pool line is removed. Type 11 or 0.4 in either box: a problem shows and Save is disabled. Sentence boxes
   show the pool's value as their placeholder. Covers the Level of difficulty checks and "writes difficulty only when".
5. **Inherited editor and saving.** Run S007.3's sentence editor checks on a pool page (editing text, rows, warnings,
   problems, unchanged sentences kept exactly, tidied names), the unsaved-changes prompt on a sidebar link, and a hand
   edit of the pool file after opening the page, which refuses the save until Reload. Covers A pool page.
6. **Rename.** Rename a sample pool that a task uses: the pool file's `name` and that task's `pools` change, one commit,
   `dw check` passes, and the child's next run of that task still works. Rename to another pool's name: refused.
   Covers Rename.
7. **Delete.** Delete a pool a task uses: Cancel is the default, then Delete is refused naming the task. Delete Year 3
   basics after taking it out of the hand-written task: the list opens without it and the file is gone, committed.
   Covers Delete.
8. **Task page and docs.** Open a parts of speech task: it shows Timeout and Correct Answers Required and a link to the
   pools, and saving a changed Timeout works. Read the Docs check's files. Covers Docs.
9. **Package.** Run `make dist` and install the package into a fresh account or a scratch `HOME`: `.env` has
   `PORT_BASE=8080` and that machine's names, `bypass.txt` names that machine and not the build machine,
   `config/parts_of_speech_pools/` holds the sample pools with `.sample` copies, and `dw up` starts. Covers the packaging
   fix in Change Summary.
