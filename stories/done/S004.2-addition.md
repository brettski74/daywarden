# User Voice

As a child, I want to be asked to add two numbers in my head, so that I can finish a revision task by getting enough of them right.

# Use Cases

- The task body sets `operation: addition`.
- The question displays `m + n =`, with a space either side of the plus sign. `m` is always on the left. The two numbers are never swapped.
- The plus sign is the ordinary `+`.
- The expected answer is `m + n`.
- The start screen names the operation "Addition".
- With `first` set, the left-hand number comes from `first`. With `first: 7`, every question is `7 + n =`.
- Zero is a valid operand. `0 + 5 =` expects 5.
- Everything else, including weights, timer, sounds, resume, and give-up, comes from the shell in S004.1.

# Acceptance Criteria

- [x] A drawn pair of 6 and 7 displays `6 + 7 =` and accepts 13 as the only correct answer. 12 and 14 are incorrect.
- [x] A drawn pair of 7 and 6 displays `7 + 6 =`. The shell treats it as a different question from `6 + 7`.
- [x] With `first` set to the single value 7, every question displays `7 + n =` with `n` drawn from `operands`.
- [x] A drawn pair of 0 and 5 displays `0 + 5 =` and accepts 5.
- [x] The start screen says "Addition".
- [x] The task uses the shell from S004.1, including weights, shrinking timer, randomly chosen sounds, resume within an hour, and the give-up control.
- [x] A finished addition task is a pass and increments today's revision count.
