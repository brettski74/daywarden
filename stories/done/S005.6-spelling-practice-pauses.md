# User Voice

As a parent, I want to set how long practice mode pauses between letters and between the word and its spelling, so that I can tune the spelling to a pace he can follow without it dragging.

# Use Cases

- The fixed 250 ms pause between letters from S005.2 makes the letter-by-letter spelling too slow. The default becomes no pause at all.
- The fixed 500 ms pause between the word and its spelling becomes 300 ms by default. It applies both ways: from the word into the first letter, and from the last letter back to the word.
- A spelling task's `body` can set both pauses:

| Field | Default | Value |
| --- | --- | --- |
| `letter_pause` | `0ms` | Pause between the letters of a spelling. A duration written as in S004.1 (`0ms`, `150ms`, `1s`), `0ms` or more. |
| `word_pause` | `300ms` | Pause between the word and its spelling, in both directions. A duration, `0ms` or more. |

- A bare number (such as `0`), a negative value, or anything that is not a duration fails the policy load, naming the task and the field.
- A change takes effect from the next time he enters practice, because practice starts a new run with the task settings in force then.

# Acceptance Criteria

- [x] With neither field set, practice plays the letters with no pause between them and pauses 300 ms between the word and its spelling in both directions.
- [x] `letter_pause` and `word_pause` set in the task body are the pauses the page receives for each step of the practice sequence.
- [x] `0ms` and `0s` are accepted for both fields. A bare number, a negative duration, or text that is not a duration fails the policy load, naming the task and the field.

# Implementation

## Files Added/Changed/Removed

Added:

- `stories/S005.6-spelling-practice-pauses.md`.

Changed:

- `policy/quiz.py`: `duration` takes `zero=True` to accept a zero duration.
- `policy/spelling.py`: `letter_pause` and `word_pause` are body fields on `Settings` (defaults 0 and 300 ms), and `practice_plan` takes them instead of the fixed 250 ms and 500 ms.
- `policy/spelling_page.py`: each practice word's steps use the run's `letter_pause` and `word_pause`.
- `tests/test_spelling.py`: the defaults, three bad values that fail the load, the plan with given pauses, and the page's step pauses for the defaults, custom values, and `0s`.
- `docs/hierarchical-policy.md`: both fields, their load checks, and practice timing.
- `stories/S005-spelling.md`: lists S005.6.

Removed: none.

## Change Summary

The two practice pauses are now ordinary spelling settings, parsed like `timeout` except that zero is allowed. They are saved with each run's settings, so the pauses in force when he enters practice are the ones he hears. The browser already followed the pauses the server sent, so the page script is unchanged.

## Suggested Acceptance Testing

### Acceptance test cases for S005.6

1. With neither field set, rebuild with `make up`, open the spelling task, and enter practice. Check the letters run straight on from each other and there is a short pause either side of each spelling.
2. Set `letter_pause: 150ms` and `word_pause: 1s` on the task, restart `decisions`, and enter practice again. Check the letters are slightly spaced and the pause around each spelling is clearly longer.
3. Set `word_pause: 0s` and check the word runs straight into its spelling and back.
4. Set `letter_pause: 0` (a bare number), then `word_pause: -1ms`, restart `decisions` each time, and check each refuses to load with a log line naming the task and the field.
