# User Voice

As a parent, I want to write capitalisation pools, set up capitalisation tasks, and read his attempts in the portal or
through an agent, so that I never have to edit the pool files by hand.

# Behaviour

## Capitalisation pools pages

- [ ] Asset Administration has a Capitalisation Pools link to `/parent/assets/capitalisation-pools`. The list, create,
      rename, delete with its refusal while a task names the pool, sign-in, and data addresses work as on Parts of
      Speech Pools in S031.2.
- [ ] A pool page shows Name and Level of difficulty as in S031.2, then one row per sentence holding a text box, a
      Level of difficulty box with the pool's value as its placeholder, and a delete button, then Add sentence.
- [ ] Add sentence and Alt+N add an empty row at the end and put the cursor in it.
- [ ] Pasting several lines into a sentence box puts the first line in that row and each other non-empty line in a new
      row below it. Pasting three lines into an empty pool gives three sentences.
- [ ] A sentence that is empty, has no capital, or appears twice in the pool, and a difficulty outside 0.5 to 10, are
      problems shown under the row that block Save.
- [ ] Save, Ctrl+S, the unsaved-changes prompt, refusal after a hand edit, and the config history commit work as in
      S031.2. A saved sentence with no difficulty of its own is written as a plain string.

## Capitalisation task page

- [ ] `/parent/tasks/capitalisation/<name>` shows Timeout, Correct Answers Required, Minimum Questions, Maximum
      Questions, and Pools, and saves them, as the parts of speech task page does in S031.3, with no Parts of speech
      filter. Empty Timeout shows `60s` as its placeholder.
- [ ] New task (S027) offers the Capitalisation type, and the Task Administration sidebar lists capitalisation tasks
      with the other types.

## Attempts

- [ ] Capitalisation attempts appear in the attempts overview and trend as `capitalisation/<name>`, with figures as
      parts of speech has in S035.1: points against the pass mark, questions against the maximum, wrong, timeouts,
      and time answering.
- [ ] The attempt page shows a summary of its last run, then each sentence in order, with each try's clicked words
      marked blue or red as in S040.1's answer, the points it earned or timeout, and the time taken, then its expired
      runs. A sentence right on its second try shows the first try with its red words and the second all blue.

## MCP tools

- [ ] The MCP page and `mcp.yaml` have a `capitalisation_pools` class with create, read, update, and delete.
- [ ] Capitalisation pools have tools to list, read, create, update, rename, and delete them, each needing its
      `capitalisation_pools` permission, which work as the sentence pool tools do in S036.1 and S036.2. Their
      sentences are in the pool file's form. Adding a sentence with no capital is refused with the page's reason.
- [ ] The task tools of S036.2 create, read, and change `capitalisation` tasks, with their pools by id. An id that is
      not a capitalisation pool, including a parts of speech pool's id, is refused.
- [ ] The attempt tools of S036.1 read capitalisation attempts with each try's clicked words.

## Docs

- [ ] `docs/parent-portal.md` names the Capitalisation Pools pages and the capitalisation task page. The MCP docs list
      the new class and tools.

# Notes

## Change Summary

Both kinds of pool use the same list page, pool page shell, `PoolAdmin`, and portal routes. A kind brings its folder, its sentence form, and its sentence check. The pool page asks the kind for its editor, which holds the blocks, judges them, and draws them. A capitalisation sentence is written as a plain string, or as a mapping with `level_of_difficulty` when its own level differs from the pool's. A sentence sent back as loaded keeps its file text exactly. A sentence that is empty or has no capital is refused when it is added or changed, with the page's wording, so a hand-written sentence the page does not touch never blocks a save.

The task page sends its `capitalisation` area under its own key, the same shape as parts of speech without `filter`. The MCP tools call the same `PoolAdmin` and task code the pages do, so refusals and commits match the portal's. A task's `pools` ids are looked up in the folder for the task's own type, so a parts of speech pool's id is refused for a capitalisation task and the other way round.

The attempt page adds a `capitalisation` section to the attempt report. Each try's words are coloured by the same rule as S040.1's answer, applied to that try's clicks. A try that is right earns the points for its place, and the sentence's last try is a timeout when the sentence timed out.

## Suggested Acceptance Testing

### Acceptance test cases for S040.2

1. Under Asset Administration open Capitalisation Pools. Make a pool, rename it, and delete an unused one, then try to delete one a task names and see it refused. Covers Capitalisation pools pages, the list, create, rename, delete, and sign-in addresses.
2. Open a pool. Check the Name and Level of difficulty, the rows with their placeholder, and Add sentence and Alt+N putting the cursor in a new row. Paste three lines into a new empty row to get three sentences. Covers the pool page, Add sentence, pasting.
3. Type an empty sentence, one with no capital, a repeat, and a level of 11, and see each problem under its row and Save blocked. Fix them and save with Ctrl+S. Check the file has plain strings, edit the file by hand and see the next save refused, and see the config history commit. Covers problems, Save, and the unsaved-changes prompt.
4. Open `/parent/tasks/capitalisation/<name>`. Check the five fields, `60s` as the Timeout placeholder, no parts of speech filter, save changes, and see it in the Task Administration sidebar. Make a task from New task with the Capitalisation type. Covers the task page.
5. Play a capitalisation task as the child with one sentence wrong then right and another timed out. Open Attempts and see `capitalisation/<name>` with points, questions, wrong, timeouts, and time answering, the trend page, and the attempt page's summary and tries with blue and red words. Covers Attempts.
6. With an agent connected and `capitalisation_pools: [create, read, update, delete]` in `mcp.yaml` (and on the MCP page), list, read, create, update, rename, and delete a pool, add a sentence with no capital and see the page's reason, create a capitalisation task with pool ids and try a parts of speech pool's id. Read the attempt and see each try's clicks. Covers MCP tools.
7. Read the Capitalisation Pools part of `docs/parent-portal.md`. Covers Docs.
